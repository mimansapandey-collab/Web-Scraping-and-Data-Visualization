
PROJECT TITLE:
Web Scraping and Data Visualization Tool

PROJECT DESCRIPTION:
This project is developed using Python.
It collects book information from a website
using web scraping techniques.

The extracted information includes:
1. Book Name
2. Book Price
3. Book Availability

The collected data is stored in a CSV file.
Matplotlib is used to create a bar graph
for visual representation of book prices.

TECHNOLOGIES USED:
1. Python
2. BeautifulSoup
3. Requests
4. Matplotlib
5. CSV

PROJECT FEATURES:
1. Automatic data collection
2. Data extraction from websites
3. CSV file generation
4. Graphical data visualization
5. Book price comparison

HOW TO RUN:
1. Install Python.
2. Install required libraries.
3. Open the project folder in VS Code.
4. Run the following command:

py main.py

OUTPUT:
products.csv
book_prices.png

CONCLUSION:
This project demonstrates how Python can
automatically collect website data and
convert it into useful graphical information.
